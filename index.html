GOOD TO KNOW

Questions, answered.

What to expect from the current PocketQwen build.

Does PocketQwen work without internet?

Ordinary model conversations can run offline after the app and bundled model are installed. Features that need current web information will require a connection when they become available.

Which model does the app use?

The current default is Qwen2.5-0.5B-Instruct in Q4_K_M quantization. Smaller models use fewer resources, but can be less capable than larger cloud models.

Does it use my phone's NPU?

We do not currently claim NPU acceleration. The app uses a native inference runtime, and performance depends on device hardware, available memory and thermal conditions.

Which Android phones are supported?

Device compatibility testing is ongoing. We will publish a tested compatibility list after validation; chipset-family claims should not be treated as a guarantee.

When can I download the APK?

A public release has not been published yet. Check GitHub Releases for the first verified build.

ABOUT POCKETQWEN

More control.
Less cloud dependence.

PocketQwen is an independent Android project exploring accessible, on-device AI. The goal is straightforward: bring a useful language model closer to the people using it, while being honest about the trade-offs of running AI on everyday hardware.
