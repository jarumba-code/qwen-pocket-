MODULE 01 IMPLEMENTED
⌘

Native, offline-first model runtime

The Android app loads a bundled Qwen model through a native llama.cpp-based runtime. Ordinary model prompts are processed on the device rather than sent to a cloud inference API.

  • Bundled Qwen2.5-0.5B-Instruct model
  • GGUF Q4_K_M quantization
  • Native inference through the app's C++ runtime
  • Configured context window: 2,048 tokens

MODULE 02 IMPLEMENTED
✳

Chat, explanations and code assistance

Ask questions, request explanations and draft code inside the conversation. The model generates text; it does not provide an integrated code execution sandbox or REPL.

binary_search.py
def binary_search(items, target):
    low, high = 0, len(items) - 1

    while low <= high:
        mid = (low + high) // 2
        if items[mid] == target:
            return mid
        if items[mid] < target:
            low = mid + 1
        else:
            high = mid - 1

    return -1

Illustrative code sample only. The website does not execute this code.

Local conversation history

Conversation records and messages are stored in an app-private SQLite database on the device. The current implementation does not claim hardware-backed encryption or semantic vector search.

DEVICE COMPATIBILITY

Built for ARM64
Android devices.

The current Android build declares API 24 as its minimum SDK and packages the native runtime for ARM64. That is a build configuration, not a promise that every device at that level has sufficient memory or performance.
